# Changelog

## 1.0.0 (2026-11-17)
- First release: Laser Rifle, Laser Battery (50), Laser Charge.
- 350 damage, ~400 RPM, 1500 m/s shots, 15% chance to set a hit target on fire (game's own fire system),
  5% chance to start a ground fire.
- Red beam visual, custom laser sound (fire.wav), other players' shots get the same beam and sound.
- Laser Charges craft from the game's battery when one is found by name.
